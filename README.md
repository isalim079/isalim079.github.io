## ⚡ About This Repository

This repository hosts the source code for Salim Reza Sumon's personal portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

### 📁 Project Structure

```
├── public/                 # Static assets (Resume, Favicon, etc.)
├── src/
│   ├── assets/             # Images, logos, and project screenshots
│   ├── components/
│   │   ├── layout/         # Header, Footer, Navbar, and Layout wrapper
│   │   ├── sections/       # Hero, About, Experience, Projects, Contact
│   │   └── ui/             # Reusable UI elements (Buttons, Cards, Badges)
│   ├── content/
│   │   └── site.js         # Centralized portfolio data & configurations
│   ├── hooks/              # Custom React hooks
│   ├── pages/              # Page views (Home, etc.)
│   ├── router/             # React Router configuration
│   ├── App.css             # Component-level styles
│   ├── index.css           # Tailwind directives & global styling
│   └── main.jsx            # React root entry point
├── index.html              # HTML template & SEO meta tags
├── tailwind.config.js      # Tailwind CSS configuration & custom theme
└── vite.config.js          # Vite configuration
```

## 🚀 Getting Started

To run this portfolio locally on your machine:

### 1. Prerequisites
- Node.js (v18.x or higher recommended)
- npm or yarn / pnpm

### 2. Clone the Repository
```bash
git clone https://github.com/isalim079/isalim079.github.io.git
cd isalim079.github.io
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build for Production
```bash
npm run build
```
